Storage

MeetingScribe stores everything in this browser's local IndexedDB storage — there's no folder to choose, since the browser (not this app) manages where that data physically lives on your device. Use Back up now below to save a portable copy you can move anywhere.

AI Engines

MeetingScribe auto-detects local engines. See docs/MODEL_SETUP.md for setup instructions.

Whisper Fully offline

Runs OpenAI's Whisper speech recognition entirely in this browser tab, on-device (a browser page cannot spawn native binaries like whisper.cpp at all, under any circumstances). Voice activity detection finds where speech actually starts and stops, then Whisper transcribes each complete phrase — so text appears a moment after you finish speaking rather than word-by-word, in exchange for much better accuracy, natural punctuation and capitalisation, and no invented words during silence. The model is bundled with this app; nothing to download or set up.

The higher-accuracy model is noticeably better at understanding speech, but it's a substantial one-time download on top of what's already bundled (about 260MB in total), and each phrase takes longer to transcribe. It's downloaded the first time you record after selecting it, then cached. If it can't be downloaded, the standard model is used instead rather than failing.

Web Speech API Not offline

Sends microphone audio to Google's servers. Off by default.

Speaker Diarization Fully offline

Real acoustic speaker identification — voice embeddings extracted on-device and clustered, not a pause-length guess. Bundled automatically; nothing to set up. Only works on meetings with a saved recording (mic/system/mixed mode) — Web Speech's transcript-only mode never saves audio, so there's nothing to analyze for those meetings. Runs as an on-demand "Detect speakers" pass in the Speakers tab after a recording finishes — not live during recording, since clustering needs the whole conversation. The ~56MB model bundle downloads once and is cached for offline use afterward.

Summaries (local LLM)

Requires Ollama or a llama.cpp server running locally, configured to allow requests from this page's exact origin (Ollama: OLLAMA_ORIGINS; llama.cpp server: --cors). This is a browser-specific requirement that didn't exist in the desktop version — see docs/MODEL_SETUP.md. Falls back to the built-in heuristic summarizer automatically if neither is reachable.

Hotkeys

These only work while this tab is focused and visible — a browser page can never receive key presses meant for other windows or apps, unlike the desktop version's OS-wide shortcuts.
